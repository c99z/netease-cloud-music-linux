# 网易云音乐 Qt 客户端功能核对

对照来源包括用户提供的已登录网页版截图、官网公开前端的栏目声明和 api-enhanced 接口源码。官网的栏目会按账号与服务端配置变化，截图外的个性化顺序需要在对应账号中复核。以下清单把浏览、详情和播放分开核对。

| 一级入口 | 已识别的子栏目与操作 | 对应接口 |
| --- | --- | --- |
| 推荐 | 推荐歌单、每日推荐、榜单精选、新歌新碟、私人漫游、喜欢的音乐 | personalized、recommend_resource、recommend_songs、toplist_detail、personalized_newsong、album_newest、personal_fm、user_playlist |
| 推荐 · 个性内容 | 风格与情绪精选、VIP 推荐、相似歌曲、大家在听。使用服务端标题、歌曲标签、封面和整组播放 | 官网调用的 /api/homepage/block/page，HOMEPAGE_BLOCK_STYLE_RCMD、HOMPAGE_BLOCK_VIP_RCMD、HOMEPAGE_BLOCK_RED_SIMILAR_SONG、HOMEPAGE_BLOCK_ALL_LISTEN |
| 推荐 · 音乐播客 | 「每天听点儿好音乐」对应音乐播客推荐，节目详情可听节目与查看包含的歌曲 | HOMEPAGE_MUSIC_PODCAST_RCMD_BLOCK、dj_program_detail。通用播客推荐单独标示 |
| 推荐 · 场景和雷达 | 雷达歌单、场景歌单、选择场景后浏览与播放 | /api/pc/customize/block/page、HOMEPAGE_BLOCK_OFFICIAL_PLAYLIST、/api/playlist/tags、/api/playlist/category/list、playlist_track_all |
| 精选 | 歌单广场分类、排行榜、新歌与新碟、歌单或专辑详情、会员歌单、会员榜单和会员推荐歌曲 | playlist_catlist、top_playlist、toplist_detail、top_song、top_album、album、官网 viptab 的歌单、榜单和歌曲接口 |
| 播客 | 推荐播客、推荐节目、分类、热门榜、新晋榜、播客和节目详情 | dj_recommend、program_recommend、dj_catelist、dj_recommend_type、dj_toplist、dj_program、dj_program_detail |
| 漫游 | 播放、换一组、下一首、播完续播、不喜欢 | personal_fm、fm_trash、song_url |

| 我喜欢的音乐 | 喜欢歌单、查看和播放、播放栏红心 | user_playlist、playlist_track_all、likelist、like |
| 最近播放 | 歌曲、歌单、专辑、播客、节目、视频 | record_recent_song、record_recent_playlist、record_recent_album、record_recent_dj、record_recent_voice、record_recent_video |
| 我的播客 | 已订阅、收藏的播客、创建、购买、喜欢的声音、最近收听 | dj_sublist、voicelist_my_created、voicelist_list、/api/social/my/subscribed/voicelist/v1、/api/voicelist/bought/list、/api/content/my/liked/voice、record_recent_voice |
| 我的收藏 | 歌单、专辑、歌手、视频 | user_playlist、album_sublist、artist_sublist、artist_songs、mv_sublist |
| 创建与收藏的歌单 | 登录后同步、创建、打开详情、继续加载曲目 | user_playlist、playlist_create、playlist_track_all |

## 已核验

- 用真实访客请求验证了推荐内容块、雷达和场景歌单、会员歌单和榜单、播客分类与节目详情、新歌新碟的地区筛选，以及歌单第二页和访客登录限制。
- Qt 桌面运行验证了推荐页双列歌曲、栏目切换、搜索，以及由 Qt Multimedia 播放真实音频。
- 用隔离账号验证了 35 个页面状态、截图中的两个栏目标题与推荐标签、302 首歌单的分页、红心切换以及漫游续播和不喜欢操作。隔离验证没有使用真实账号，也没有发送真实收藏或偏好修改。

## 与网页版对齐（2026-11-19）

对照已登录的 music.163.com/st/webplayer 逐页核对后调整的部分：

- 外观：默认浅色主题（白底、红色强调、红色胶囊选中态），顶栏的换肤按钮和账号菜单可切换深色，选择会保存。
- 顶栏：返回键（含 Alt+←）、搜索框热搜榜和输入联想、头像昵称下拉菜单（我的主页、切换皮肤、退出登录）。
- 推荐：轮播图、「猜你最近喜欢听」、精选推荐（每日推荐、私人漫游与雷达歌单）、带播放量的推荐歌单、官方榜前三名及升降标记、雷达歌单，以及 VIP 推荐、为你定制、音乐播客、场景歌单等货架。
- 精选：文字下划线标签；歌单广场的分类胶囊和「更多分类」分组弹层；排行榜按榜单推荐、官方榜、精选榜、曲风榜等分组；歌手页地区、类型、首字母筛选与圆形头像。
- 歌曲列表：SQ、VIP 标签，每行红心，悬停出现收藏和更多按钮，右键菜单（播放、下一首播放、喜欢、收藏到歌单、复制链接、从歌单删除），点歌手或专辑名可跳转。
- 歌单详情：大封面、简介、创建者和创建时间、收藏歌单、复制链接，歌曲 / 评论 / 收藏者三个标签，列表内搜索，滚动到底自动加载。专辑与歌手页共用这套布局，歌手页有专辑、歌手详情、相似歌手。
- 搜索：单曲、歌单、歌手、专辑、播客分类。
- 播放：底部栏为圆形旋转封面、居中的红心与播放模式；全屏播放页为黑胶唱片与唱臂，右侧歌词或相似推荐（相关歌单、相似歌曲）。点击侧栏「漫游」直接开播并打开播放页。
- 播放列表：可从列表删除、清空。
- 播放模式（底部栏循环按钮依次切换，选择会保存，非默认模式时按钮为红色）：
  - 列表循环：最后一首播完回到第一首。
  - 单曲循环：播完重播当前歌曲；手动上一首、下一首照常切歌，无法播放的歌会被跳过。
  - 随机播放：按随机排列逐首播放，一轮内不重复，新一轮不会紧接着重复刚播完的歌；「上一首」退回真正播过的上一首；「播放全部」从随机一首开始；「下一首播放」仍然排在当前歌后面。
  - 顺序播放：最后一首播完即停止，此时下一首按钮不可用。
  - 漫游时按推荐顺序续播，模式按钮不可用。

## 尚未核验的差异

- 已登录网页版的完整会话在本次工具中不可操作。按账号和服务端实验分配的版块标题、顺序、展示条件和数据量，仍需用实际账号逐项复核。
- 桌面音乐播客区块缺席时显示名称独立的「音乐播客推荐」。节目本身与关联歌曲走节目详情接口。
- 收藏与最近播放的视频在官网打开。购买页只浏览已购内容，界面不包含交易流程。
- 本表覆盖侧栏与推荐子页面。
- 仍与网页版不同：播客首页没有轮播和分类胶囊，「我的播客」用卡片而不是列表，关注动态没有内嵌歌曲卡片和点赞评论，没有发布动态、消息和设置页，排行榜不显示两个 H5 畅销榜，VIP 页没有会员信息卡和有声书货架，搜索没有「综合」分类，评论只读不可发布。
